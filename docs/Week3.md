E1-P4
曖昧プロンプト本文：
台風のとき、避難した方がいいですか。
使用した出力：
Web版生成AI / ローカルLLM / サンプル出力
出力の要約：
・台風接近時の避難判断と行動
自治体から警戒レベル3以上の避難情報が出た場合や、浸水・倒壊の危険がある地域では直ちに避難すべきだ。暗くなる前や風が強まる前に、動きやすい服装で徒歩にて指定避難場所へ移動する。浸水が激しい際は無理に外へ出ず、建物の上階へ垂直避難を行い自らの安全を最優先に確保する。
誰向けか不明だった点：
腰の弱い年寄りなどに避難場所が遠くても避難するべきだと言い切れるか不明。
地域・場面が曖昧だった点：
どこのどんな自治体のことを言っているのか分からない。浸水・倒壊が起こってる地域だから避難するというのはどの規模を指しているのか分からない。
根拠・出典の有無：
有
危険な断定・不確実性：
建物の上階とはどれくらいの高さか、自治体から出た警戒レベル3以上と言ってもその前提を確実だと捉えて、直ちに避難するというのは適切なのかなど
次に追加したい条件：
比較できない。
残ったリスク：
身体状況。具体的な状況と行動を示しているが、他にもいろいろな状況があり、行動もその場で変わってくるので信頼に値しない情報である。

E1-P5
曖昧プロンプト本文：
高齢者向けに、台風接近時の避難判断について説明してください。
使用した出力：
Web版生成AI / ローカルLLM / サンプル出力
出力の要約：
・台風時の避難判断と行動
-避難情報と判断基準
・自治体から警戒レベル3の高齢者等避難が出たら、早めに避難を開始する。
・危険な場所では警戒レベル4の避難指示に従い、明るいうちに徒歩で指定場所へ移動する。
・浸水時や移動が困難な場合は、無理をせず建物の上階へ移る垂直避難を行う。
誰向けか不明だった点：
高齢者に向けているはずだが、無理をしないでという文言のみで、高齢者の場合の行動に変化は見られなかった。
地域・場面が曖昧だった点：
なぜか警戒レベル4の状態のみを想定しているため、限定的すぎる。高齢者であれば、さらに警戒レベルが低くてもしっかり警戒する必要がある。
根拠・出典の有無：
有
危険な断定・不確実性：
早めの避難を呼びかけているが、それは誰にでも言える。誰だって早めに避難した方が良い
次に追加したい条件：
比較はしやすいが、高齢者の部分を他の対象に変換したときに、同じように内容に変化がないのであればプロンプトの方向性を変えるひつようがある。
残ったリスク：
移動困難時の対応。高齢者に向けての内容の変化がほとんど見られない。

洪水ハザードマップを見る注意点を、�条書きで説明してください。

出力の要約：
・洪水ハザードマップの活用における注意点
-マップの前提とリスク
・想定最大規模の降雨に基づいた最悪のシナリオであることを理解する。
・浸水想定外の地域でも局地的な大雨で浸水する可能性がある。
・浸水深だけでなく水の勢いや周囲の土砂災害リスクも考慮する。
・最新版の確認とマイ・タイムラインの作成で事前備えを徹底する
誰向けか不明だった点：
誰向けかは不明である。誰がどのように使うハザードマップなのか指定がない
地域・場面が曖昧だった点：
想定の最大規模の降雨を前提にするということで、最も最悪のリスクを避けられるのでそれ以外の小さい洪水等でも対応できるので良いと思った。
根拠・出典の有無：
無
危険な断定・不確実性：
浸水地域以外の地域でも大雨などで浸水する可能性を指摘している点は良かったが、ハザードマップの情報は、今までの統計の最大降水量をもとに製作しているだろうから、これから過去最大の降水量となりより被害が大きい場合を想定できていない。
次に追加したい条件：
かなり比較しやすくなった。箇条書きになったことで見やすさが向上した。

地図の限界など。周囲の土砂災害リスクも考慮できている点が良かった。リスクとしては、土砂がどれだけ迫ってくる可能性があるかという点も明記するべきだと思った。
